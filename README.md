# TikWork
TikTok like app but for find job
![screenshot mobile tikwork](https://raw.githubusercontent.com/bagusindrayana/tikwork-nativephp/refs/heads/master/Screenshot_20260206_235009-portrait.png)


## Tech Stack
- Laravel 12
- NativePHP
- Tailwind CSS
- Alpine.js

## Development
- composer install
- npm install
- copy .env.example to .env
- set `API_URL` to api from `https://github.com/bagusindrayana/tikwork-api`
- php artisan key:generate
- php artisan migrate
- npm run dev
- php artisan serve

## NativePHP
- php artisan native:install
- php artisan native:run
